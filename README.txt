Before using this in an Instagram or TikTok bio:
1. Replace every CONTACT_EMAIL_PLACEHOLDER in index.html with your real contact email address.
2. Add TikTok and Meta pixels only if needed, then update the privacy policy to describe the tracking used.
3. If hosting on a different domain, update the og:image URL to the full address of that domain's og-image.png.
4. Review the linked seller pages and their policies.
